# futbol-efsaneleri# Futbol Efsaneleri

Bu proje BPR201 İnternet Tabanlı Programlama dersi kapsamında hazırlanmıştır.

## Proje Amacı

Futbol tarihine damga vurmuş efsane futbolcuları tanıtmak ve kullanıcıların arama özelliği sayesinde istedikleri futbolcuyu kolayca bulmalarını sağlamaktır.

## Hedef Kitle

Futbol severler ve futbol tarihine ilgi duyan kişiler.

## İçerikler

- Pelé
- Diego Maradona
- Johan Cruyff
- Lionel Messi
- Cristiano Ronaldo

## Özellikler

- Başlığa göre arama
- Sonuç sayacı
- Temizle butonu
- Mobil uyumlu tasarım
- Ortak gezinme menüsü
